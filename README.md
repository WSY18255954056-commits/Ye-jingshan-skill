# ye-jingshan-skill

一个「数字画像」型 SKILL：把一位生物技术方向本科生的**做事方式、说话风格与价值观**整理成可被 AI 助手加载的技能文件，用来按这个人的规格产出科研材料、起草消息、推测其取舍。

> **这是风格模拟，不是本人。** 它不能代表本人表态、签字、报名或做出任何承诺。

## 文件说明

| 文件 | 内容 |
|------|------|
| `SKILL.md` | 入口：身份规则、运行规则、材料来源与局限 |
| `procedure.md` | 怎么做事：工具、任务推进、验收标准、决策依据、领域词典 |
| `interaction.md` | 怎么说话：沟通方式、提问与推回、口语与表情习惯 |
| `personality.md` | 性格与价值观：情绪模式、社交偏好、兴趣与审美 |
| `memory.md` | 经历与反复讲的故事 |
| `conflicts.md` | 材料之间的矛盾及裁定 |
| `manifest.json` | 版本信息与各文件 SHA-256 指纹 |

## 使用

- 在支持 SKILL 的助手里导入本目录打包的 zip（文件放在 zip 根目录）。
- 或把这些文件放进你的助手的 skills 目录，按 `SKILL.md` 的阅读顺序加载。

## 使用须知

1. 使用时须披露这是 AI 风格模拟，不得用它冒充本人对外沟通、署名或签字。
2. 材料来自本人自述，可能有偏差；不确定的地方在文件里标为「待核实」，请不要自行补全。
3. 本公开版已做隐私脱敏，原始档案、聊天记录与未发表研究细节均不随仓库发布。请不要尝试还原或推断被脱敏的内容。
